## 追加のしかた

1. `_TEMPLATE.md` をコピーする
2. ファイル名は `YYYY-MM-<company>-<topic>.md`（例: `2026-09-nike-brand-decline.md`）
3. 冒頭のYAMLメタ情報（company / industry / type / theme / tags / source / source_url / source_date / logged）を埋める
4. **原本を確保する**（下記「出典の確保」）
5. 上の一覧表に1行追加する

## 出典の確保

紙面・雑誌の切り抜きは、写真を撮っただけでは後で引用できない。必ず次まで済ませる。

1. **元記事のURLを特定する**（見出し＋固有名詞で検索）
2. **記事IDを控える**（日経なら `DGXZQ...`。URLが切れても日経テレコンで再取得できる）
3. **一次情報に当たる**（決算はIR／SEC、指数変更はS&P DJIのリリース、調査は調査会社の原典）
4. **記事の数字と一次情報が食い違ったら、その差分ごと記録する**（消さない。どちらが正しいかの判断材料になる）
5. 紙面のスキャン画像は著作権の観点からリポジトリにコミットしない。原本は手元保管し、正典はURL・記事IDで参照する

## 書くときの方針

- **事実と解釈を分ける**：「何が起きたか」は出典どおりの数字で、「構造」「理論との接続」は自分の解釈として書く
- **数字は必ず期間と基準を添える**（例: 26年5月期、2年前比、23→25年の平均年成長率）
- **読み取りに自信がない箇所は「未確認・要検証」に逃がす**。後で一次情報に当たれるようにする
- **記事はしばしば「その後」を書いていない**。一次情報で直近の打ち手まで追うと、事例の価値が上がる
- **抽象化した教訓**を必ず1行以上書く。事例は抽象化して初めて再利用できる
