# ナイキ｜直販偏重と「希少モデル商法」でブランド力を削った失敗

## 1行サマリー

利益率の高い直販（アプリ・D2C）と、コラボ限定モデルによる希少性販売に傾倒した結果、
**量販店という消費者接点**と**本業である高機能シューズのイノベーション**の両方を手放し、
株価12年ぶり安値・S&P100除外まで転落した。

## 何が起きたか（事実・数字）

| 指標 | 数値 | 備考 |
|---|---|---|
| 株価 | 12年ぶりの低水準 | |
| 転落の起点 | 2024年6月 | 業績見通しの悪化を機に1日で株価が約2割下落。その後も好転せず |

## 構造（なぜそうなったか）— 記事が挙げる3要因

### ① 米国での量販店チャネルの弱体化

- コロナ禍の外出制限下で、**アプリを使った直販**に注力。在宅トレーニングの管理やレッスンもできるアプリが人気を博し、直販比率が大幅に上昇した。
- 直販の**利益率の高さに味を占め**、DSW・フットロッカーなど米量販店をないがしろにした。
- 量販店は「消費者との接点として重要な売り場」。そこでのプロモーション機会が減り、**ブランド認知が低下**した。

> 短期の粗利率（直販>卸）を最大化した結果、長期のブランド露出・新規顧客獲得チャネルを自ら痩せさせた。

### ② 「希少モデル商法」の行き過ぎ

- 1985年、マイケル・ジョーダンと契約して開発した「エアジョーダン」を発売。以後、**超有名スポーツ選手とのコラボ**に注力。
- これらの**数量限定モデル**を次々に投入。一時は高値で転売されるほどのブームとなり収益を上げた。
- しかし**ファンの熱狂がさめると通用しなくなった**。
- むしろ、限定デザインの販売に血道をあげている間に、**一般消費者が求める高機能シューズ分野でイノベーションの手が止まった**。

> 人工的希少性は需要を「前借り」する。転売市場の過熱は指標としては好調に見えるが、実需（履くために買う人）の成長とは別物。

### ③ 大きくなりすぎて復元力を失った

- 事業規模の3割強を、アパレルやスポーツ用品など**靴以外の事業**が占める構造になり、動きが鈍重に。
- 履物業界に詳しいコンサルタント、アン・ウィリアムズ氏は、**小回りがきき消費者と密接なコミュニケーションができている**On・HOKAなどの新興ブランドとの差が埋まらない、と指摘。

## 因果の見取り図

```
[短期の利益率志向]

   └─ 限定/コラボ偏重 ─→ 転売ブームで一時的に増益                        ├─→ ブランド認知の低下
                        └→ 熱狂の減衰＋高機能シューズの開発停滞 ─────────┘        （17年26位→26年80位）
                                                                              │
                       On / HOKA など機能特化・小回りの利く新興が空席を獲得 ←───┘
                                                                              │
                                          売上10%減・時価総額1/5・S&P100除外 ←─┘
```

## マーケティング／経営理論との接続

- **チャネル・ケイパビリティの不可逆性**：卸・量販チャネルは「切れば戻せる」ものではない。棚と販売員は撤退した瞬間に競合で埋まる。D2C移行の議論では、粗利率の改善分と失う認知・トライアル機会を同じ土俵で比較すべき。
- **希少性マーケティングの逓減**：人工的希少性は「熱狂」が燃料。燃料（コラボの新鮮さ・転売差益）が尽きると、残るのは「買えない／高い」という負の記憶。ブランドエクイティを消費して短期売上に換金する行為に近い。
- **コア・ベネフィットからの逸脱**：ナイキの本来の競争優位は機能性（ランニング等）。そこへの投資を止めた隙に、機能軸に特化した新興（On=クッショニング、HOKA=厚底）に侵食された。破壊的イノベーションというより、**主戦場の放棄による正面からの侵食**。
- **規模と俊敏性のトレードオフ**：多角化（非シューズ3割強）が意思決定の重心を鈍らせ、消費者との対話速度で新興に劣後した。
- **経営者の出自と施策の相性**：EC出身CEOによる直販最適化は、プラットフォーム事業では正解でも、ブランド×リアル売り場が資産の事業では副作用が大きかった可能性。

## 抽象化した教訓

1. **利益率の高いチャネルへの集中は、認知の総量を減らす方向に働くことがある。** 収益性指標だけで見ると正しく見えるのが厄介。
2. **限定・希少性による売上は、需要創造ではなく需要の前借りかもしれない。** 転売価格をKPIに入れてはいけない。
3. **「話題づくり」と「本業の性能改善」はリソースを奪い合う。** 前者が回っている時期ほど、後者の停滞が見えにくい。
4. **ブランド力の劣化は遅行指標で表れる。** 業績悪化（24年6月）より前から進行し、ランキング（17年→26年）で可視化された時にはすでに手遅れに近い。
