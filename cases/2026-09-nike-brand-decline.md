## 1行サマリー

利益率の高い直販（アプリ・D2C）と、コラボ限定モデルによる希少性販売に傾倒した結果、
**量販店という消費者接点**と**本業である高機能シューズのイノベーション**の両方を手放し、
株価12年ぶり安値・S&P100除外まで転落した。

### 数字の検証（重要）

記事の「26年5月期の売上高は463億ドル、2年前比10%減」は、公式決算と照らすと**期のラベルが1年ずれている可能性**がある。

- FY2024（24年5月期）：**514億ドル**
- FY2025（25年5月期）：**463億ドル**（前期比 **-10%**）← 「463億ドル」「10%減」はこの期の数字と一致
- FY2026（26年5月期）：**464億ドル**（前期比フラット、為替中立で-2%）

いずれの読みでも「**2年で約10%減り、その後46億ドル台で下げ止まったまま横ばい**」という実像は変わらない。
引用するときは**FY2026＝464億ドル／FY2024比 約-10%**と書くのが安全。

## 構造（なぜそうなったか）— 記事が挙げる3要因

### ① 米国での量販店チャネルの弱体化

- コロナ禍の外出制限下で、**アプリを使った直販**に注力。在宅トレーニングの管理やレッスンもできるアプリが人気を博し、直販比率が大幅に上昇した。
- 直販の**利益率の高さに味を占め**、DSW・フットロッカーなど米量販店をないがしろにした。
- 量販店は「消費者との接点として重要な売り場」。そこでのプロモーション機会が減り、**ブランド認知が低下**した。

> 短期の粗利率（直販>卸）を最大化した結果、長期のブランド露出・新規顧客獲得チャネルを自ら痩せさせた。

### ② 「希少モデル商法」の行き過ぎ

- 1985年、マイケル・ジョーダンと契約して開発した「エアジョーダン」を発売。以後、**超有名スポーツ選手とのコラボ**に注力。
- これらの**数量限定モデル**を次々に投入。一時は高値で転売されるほどのブームとなり収益を上げた。
- しかし**ファンの熱狂がさめると通用しなくなった**。
- むしろ、限定デザインの販売に血道をあげている間に、**一般消費者が求める高機能シューズ分野でイノベーションの手が止まった**。

> 人工的希少性は需要を「前借り」する。転売市場の過熱は指標としては好調に見えるが、実需（履くために買う人）の成長とは別物。

### ③ 大きくなりすぎて復元力を失った

- 事業規模の3割強を、アパレルやスポーツ用品など**靴以外の事業**が占める構造になり、動きが鈍重に。
- 履物業界に詳しいコンサルタント、アン・ウィリアムズ氏は、**小回りがきき消費者と密接なコミュニケーションができている**On・HOKAなどの新興ブランドとの差が埋まらない、と指摘。

## 因果の見取り図

```
[短期の利益率志向]
   ├─ 直販シフト ──→ 量販店との関係悪化 ──→ 売り場での接点・販促機会の喪失 ─┐
   └─ 限定/コラボ偏重 ─→ 転売ブームで一時的に増益                        ├─→ ブランド認知の低下
                        └→ 熱狂の減衰＋高機能シューズの開発停滞 ─────────┘        （ランキング後退）
                                                                              │
                       On / HOKA など機能特化・小回りの利く新興が空席を獲得 ←───┘
                                                                              │
                                    売上約10%減・時価総額1/5・S&P100除外 ←──────┘
```

## その後の打ち手（FY2026決算で確認できる方向転換）

記事は転落の記述で終わっているが、**一次情報を見ると原因①の巻き戻しが実際に始まっている**。
FY2026（26年5月期）のチャネル別内訳がそれを示す。

| チャネル | FY2026売上 | 前期比 |
|---|---|---|
| **卸売（Wholesale）** | 275億ドル | **+6%** |
| NIKE Direct（直販） | 177億ドル | **-6%** |
| うち NIKE Brand Digital | — | **-12%** |

- 直販を縮め、**卸・量販チャネルを積極的に再構築している**。診断（量販店軽視が誤りだった）と処方（卸を戻す）は一致している。
- ただし全体売上はフラット。**チャネルを戻しても、失ったブランド認知と製品競争力はまだ戻っていない**というのがこの事例の核心。
- なお中華圏は8四半期連続の減収で、記事の3要因に加えて**中国市場の不振**が重石になっている。

> 教訓としてはむしろこちらが重要：**チャネルは方針転換すれば2年で戻せるが、ブランド認知と製品開発の遅れはそれより遥かに遅く戻る。**

## マーケティング／経営理論との接続

- **チャネル・ケイパビリティの非対称性**：卸・量販チャネルは「切れば戻せる」ものではない。棚と販売員は撤退した瞬間に競合で埋まる。撤退は速く、再構築は遅い（実際、卸を+6%まで戻すのに複数年かかり、それでも全体売上は戻っていない）。D2C移行の議論では、粗利率の改善分と失う認知・トライアル機会を同じ土俵で比較すべき。
- **希少性マーケティングの逓減**：人工的希少性は「熱狂」が燃料。燃料（コラボの新鮮さ・転売差益）が尽きると、残るのは「買えない／高い」という負の記憶。ブランドエクイティを消費して短期売上に換金する行為に近い。
- **コア・ベネフィットからの逸脱**：ナイキの本来の競争優位は機能性（ランニング等）。そこへの投資を止めた隙に、機能軸に特化した新興（On＝クッショニング、HOKA＝厚底）に侵食された。破壊的イノベーションというより、**主戦場の放棄による正面からの侵食**。
- **規模と俊敏性のトレードオフ**：多角化（非シューズ3割強）が意思決定の重心を鈍らせ、消費者との対話速度で新興に劣後した。
- **経営者の出自と施策の相性**：EC出身CEOによる直販最適化は、プラットフォーム事業では正解でも、ブランド×リアル売り場が資産の事業では副作用が大きかった可能性。

## 抽象化した教訓

1. **利益率の高いチャネルへの集中は、認知の総量を減らす方向に働くことがある。** 収益性指標だけで見ると正しく見えるのが厄介。
2. **限定・希少性による売上は、需要創造ではなく需要の前借りかもしれない。** 転売価格をKPIに入れてはいけない。
3. **「話題づくり」と「本業の性能改善」はリソースを奪い合う。** 前者が回っている時期ほど、後者の停滞が見えにくい。
4. **ブランド力の劣化は遅行指標で表れる。** 業績悪化（24年6月）より前から進行していた。
5. **戦略の誤りに気づいて巻き戻しても、資産の回復速度はチャネル＜ブランド認知＜製品競争力の順に遅い。** 「戻せばいい」で許容できるリスクではない。

## 関連事例との対比：シーブリーズ（[2026-09-seabreeze-repositioning.md](2026-09-seabreeze-repositioning.md)）

同じ「ブランド資産」という変数を、**逆向きに操作した2社**として並べて読める。

| | ナイキ | シーブリーズ |
|---|---|---|
| ブランド資産への操作 | **消費**（希少性で換金） | **再投資**（休眠記憶を掘り起こす） |
| 利用シーン | 限定・コレクター向けに**狭めた** | 通勤・仕事・現場へ**広げた** |
| チャネル | 量販店を**切った**（直販へ集中） | 自販機・法人を**足した** |
| 製品開発 | 高機能シューズの手が**止まった** | 形状刷新＋新カテゴリーで**動かした** |
| 結果 | 売上-10%、時価総額1/5、S&P100除外 | 市場横ばいの中で売上が前年比プラスに転換 |

> **共通する軸**：ブランドが強い企業ほど、「どの場面で使われるか」の数を増やしたか減らしたかが結果を分けている。粗利率やブランドの話題性は、この軸の前では副次的。
